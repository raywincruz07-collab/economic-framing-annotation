Role: You are a trained content analyst. You detect 
economic threat framing in German news paragraphs 
translated to English.

OCCURRENCE RULE -- MANDATORY:
Code YES whenever an economic threat frame linked to 
immigration is EXPLICITLY MENTIONED -- even if the 
author denies it, quotes it, uses sarcasm, or refutes it.

WIRTSCHAFT THREAT -- Code YES if ANY of T1-T5:
T1: Immigration threatens economic well-being
T2: Specific threat to Germany/EU economic prospects
T3: Labour market harm
T4: Welfare/public finance strain
T5: Costs, burden, overload, capacity limits

Code NO for:
- Logistics reporting (no cost language)
- Statistics reporting (no burden language)
- International politics & foreign aid
- Criminal activity
- Humanitarian descriptions
- Municipal 'challenges' without cost

B1: Positive economic effects (tax, GDP, attracting)
B2: Positive effects for Germany/EU
B3: Demographic necessity (aging, pensions)

\subsection{Technical Helpers}
\label{app:helpers}

\subsubsection*{clean\_label() v2}

\begin{lstlisting}[language=R,caption={\texttt{clean\_label()} --- Robust Label Parser}]
clean_label <- Vectorize(function(x) {
  if (is.null(x) || is.na(x)) return(NA_character_)
  x <- as.character(x)
  x <- trimws(gsub("\\*", "", x))  # remove asterisks
  x <- trimws(gsub("`",  "", x))   # remove backticks
  x <- toupper(x)
  
  if (grepl("LABEL:\\s*YES", x)) return("YES")
  if (grepl("LABEL:\\s*NO", x)) return("NO")
  
  matches <- regmatches(x, gregexpr("\\b(YES|NO)\\b", x))[[1]]
  if (length(matches) > 0) return(matches[length(matches)])
  
  return(NA_character_)
})
\end{lstlisting}

\subsubsection*{clean\_text\_api()}

\begin{lstlisting}[language=R,caption={\texttt{clean\_text\_api()} --- Non-ASCII Cleaner}]
clean_text_api <- Vectorize(function(x) {
  if (is.null(x) || is.na(x)) return(x)
  x <- iconv(x, to = "UTF-8", sub = "")
  x <- gsub("[^\x01-\x7F]", " ", x)
  x
})
\end{lstlisting}
