
\section{Conclusion}
\label{sec:conclusion}

This project successfully developed and deployed an LLM-assisted pipeline to annotate a 10,000-row corpus of German immigration news. While the development-stage pilot demonstrated high preliminary performance, the final untouched 1,002-row evaluation provided a more conservative assessment. The model successfully detected most human-positive frames (high recall), but generated more positive predictions than the human consensus, leading to low precision. Consequently, the main final limitation is precision rather than recall. 

Further work should focus on reducing false positives. Importantly, the final evaluation sample was not used for prompt tuning. Reliability statistics must be interpreted cautiously because paired submitted files were identical, meaning independent human agreement cannot be definitively proven from file evidence alone.
