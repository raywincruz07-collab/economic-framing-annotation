# Bacchuss Routine Mapping

This document maps the project's technical implementation to the Freudenthaler **bacchuss annotation routine**.

## 1. Routine Alignment

- **Step 1: Annotation Instructions**
    - Defined in `config.R`. Contains the core role description, sub-criteria (T1–T5 and B1–B5), and the "Occurrence Rule."
- **Step 2.1: 200-row Test Sample**
    - Executed via `scripts/step0_draw_sample.R`. Draws a fixed, reproducible sample of 200 paragraphs from the full 10,000-row corpus.
- **Step 2.2: Repeated/Hard-case Checks**
    - Handled by `scripts/step2_2_hardcases.R`. Identifies inconsistencies in classification across multiple runs at high temperature to uncover ambiguous text blocks.
- **Step 2.3: Prompt Refinement**
    - Documented in `reports/prompt_version_log.csv`. Tracks the iterative improvement of the annotation logic across 8 iterations based on failure analysis.
- **Step 3: Human Gold Labels**
    - Stored in `data/validation/human_gold_validation.csv`. Represents the human ground truth used to calculate precision, recall, and F1.
- **Step 3.2: Few-shot / Reasoning Improvements**
    - Implemented in `scripts/step3_2_fewshot_cot.R`. Uses Chain-of-Thought reasoning and targeted training blocks to resolve classification errors identified in baseline tests.
- **Step 4: Validation Metrics**
    - Generated by `scripts/step4_validation.R`. Produces the final classification reports (Precision, Recall, F1) against the human gold standard.
- **Step 5: Full 10k Corpus Annotation**
    - Final production run executed by `scripts/step5_full_annotation.R`. Processes the entire translated dataset using the validated production prompt.

## 2. Limitations

- **Intercoder Reliability:** The template for human-human reliability is provided in `data/intercoder/`. Actual overlap annotations and reliability coefficients are included only in the full academic submission package.
- **Data Availability:** Large raw and final annotated datasets are excluded from this public repository but are available in the formal submission.
