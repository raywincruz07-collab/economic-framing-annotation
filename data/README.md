# Data Availability

## Privacy and Licensing
The source corpus and the row-level annotated dataset (`final_annotated_10k.csv`, `sample_1002_master.csv`, `gold_200.csv`) are excluded from this public repository due to copyright restrictions on the original news texts and privacy policies regarding intermediate annotation consensus files.

## Included Data
Only aggregated metrics, summary tables, and training block examples are provided in the public repository. Researchers wishing to reproduce the study with the full dataset must request access from the principal investigators.
